# Enveda CASMI 26 — Molecule ID from Mass Spectra: solution

Pipeline for the Kaggle competition [Enveda CASMI 2026 - Molecule ID From Mass
Spectra](https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra):
predict up to 25 ranked SMILES guesses per molecule from `test.parquet`.

The scored engine is the public 4-channel fork under `vendor/haideptry-casmi26` and `kaggle/casmi26-fork-v4-cpu`. Meanings of MRR and class 1, class 2, and class 3 are in `docs/mrr-and-classes.md`. Analog `scripts/pipeline.py` is a weaker local baseline, not the submit path.

## Method (analog baseline; see `CASMI26_solution.ipynb` for details)

1. **Dedup on the metric key.** Candidate pool = `train.parquet` deduplicated on
   `inchikey14` (the metric key: first 14 chars of the InChIKey of the
   tautomer-canonicalized molecule).
2. **Mass matching.** Per-adduct Da shift and a 0.005–0.05 Da window, same-mode
   monomer hypotheses (`scripts/pipeline.py:mass_candidates`).
3. **Evidence channels.** Spectral cosine (query vs the molecule's library
   spectra), Morgan-FP Tanimoto to the spectral winner, in-silico fragment
   coverage, popularity, and natural-product / documentation priors. Blended by a
   LightGBM ranker (`LGBMRanker`).
4. **Public-ranker ensemble.** LightGBM features include rank features from three
   public rankers reimplemented in the repo: the v8 mass rule + isomer rerank
   (mathleteutd `casmi26-aprior-uniq-10-network-anchors`), the anchored network
   with POP/SPEC/NP priors + `LIB_HIT_GATE = 0.78` (flexonafft
   `casmi26-anchored-spectral-network`), and the haideptry starter (candidate
   retrieval + rerank across four channels).
5. **Local validation.** Held-out train spectrum per molecule, identity-disjoint
   5-fold CV on 200 keys, held-out `enveda-np-examples` panel. Empty retrievals score 0.
6. **Output.** `submission.csv` (columns `molecule_id`, `smiles`; up to 25 guesses
   semicolon-separated).

## Files

- `data/train.parquet`, `data/test.parquet`, `data/sample_submission.csv` — competition data
- `data/pool.parquet`, `data/pool_spec.npz`, `data/adduct_offsets.json` — built library (cache; the notebook does not rebuild it)
- `data/model.pkl` — final blend model (saved by `scripts/validate.py`)
- `submission.csv` — generated by `scripts/score_test.py`
- `scripts/pipeline.py` — the pipeline (mass matching, channels, rankers, validation helpers)
- `scripts/validate.py` — identity-disjoint 5-fold CV + natural-product panel benchmark
- `scripts/score_test.py` — test scoring -> `submission.csv`
- `scripts/build_library.py` — library build (idempotent; only needed if `data/pool.parquet` is missing)
- `scripts/smoke_test.py` — quick plumbing check on a few molecules
- `scripts/make_notebook.py` — assemble `CASMI26_solution.ipynb` from the tested code
- `CASMI26_solution.ipynb` — self-contained solution notebook

## Run

```
python scripts/validate.py     # local validation: 5 folds + panel; saves data/model.pkl
python scripts/score_test.py  # test scoring; writes submission.csv
```
